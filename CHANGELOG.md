# Changelog

Release history for iTrans (MacTranslate AI). Downloadable assets for each release are available on the [GitHub Releases](https://github.com/cduyzh/iTrans/releases) page.

## 1.0.1 — 2026-10-29 (Build 2): Google and DeepSeek only

- Removed the MyMemory translation engine from engine selection and translation requests.
- Existing MyMemory engine preferences now migrate to Google.
- Engine cycling now switches only between Google and DeepSeek.

## 1.0.0 — 2026-10-29 (Build 1): Initial Official Release

- Ultra-fast native macOS menu bar translation utility deeply integrating Google Web RPC and DeepSeek reasoning models with offline self-learning translation memory.
